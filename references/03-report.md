# HTML 精读报告规范

交付形态：单文件自包含 `.html`，遵循 `html` skill 规范（写前完整读 html/SKILL.md 与 references/design/frontend-design.md）。报告内结构化关系（章节地图/概念关系/流程）遵循 `doubao-visualization` 规范绘制。

## 必备章节

1. 书籍信息卡：书名 / 作者 / 主题 / 精读日期 / 解析方式
2. 一页纸结论：核心思想、全书结构、可带走的一句话
3. 阅读意图问题与解答：Q&A 清单（每个问题对应原文依据）
4. 章节地图：目录结构可视化（树状/时间轴/流程图按内容选型）
5. 核心概念与费曼讲解：每概念 = 大白话 + 原文锚点 + 跨领域联结
6. 金句摘录：引用 + 出处 + 一句话点评
7. 自测题：白纸法 + 闪卡式 Q&A
8. 来源与免责：解析方式、待核项、未覆盖章节

## 硬约束

- 数据保真：数字/观点必须来自原文，可追溯，不凑整不编造
- 初始静态可读：核心内容不依赖 hover/脚本承载
- 响应式：电脑与手机端均可读（先 375px 再桌面扩展）
- 交付前用 html skill 的 `scripts/shot.py` 自检；最终回复从简
