# Logseq 落库规范

## 图库解析

- 优先读环境变量 `LOGSEQ_GRAPH`；未设置时使用本机 Logseq 图库默认路径（部署时按本机实际情况填写，如 `/Users/<你的用户名>/Documents/mylibrary`）
- 运行时先探测图库目录是否存在；**图库可达时卡片直接写入其 `pages/`（默认行为，书页+概念页+卡片页一并落库）**；不可达则降级输出（见下）

## pages/ 结构

```
pages/
├── 《书名》.md          书页（元数据 + 一页纸结论 + 章节地图 + 卡片索引）
├── 概念-《书名》-X.md    概念页（费曼解释 + 双链 + 原文锚点）
└── 金句-《书名》-N.md    卡片页（quote/method/question）
```

## Logseq 语法要点

- 属性：`key:: value`（双冒号 + 空格，页面首块）
- 双链：`[[页面名]]`；标签：`#标签`
- 块引用：`((block-id))`（卡片间精确引用时用）
- 金句引用块：`> 原文`（quote 卡正文行）
- 页面标题用 `# 页面名`；内容用大纲 bullet `-`（Logseq 原生形态）
- 页面首块是属性区，随后是正文

## 闪卡（Card）规范

- 卡片页正文以 h3 标题 + 闪卡标识开头：`### 标题 #card`（`###` 后空格，`#card` 前空格）
- 标题下的答案内容统一缩进下一级（`- ` bullet），多行直接换行、每行一个块，便于树形浏览与按块引用
- 关联概念用二级缩进子块：`- 关联：` → `  - [[概念-《书名》-X]]`
- Logseq 中 `#card` 标记的块进入闪卡复习队列（Cards 功能），标题即问题、子块即答案

## 降级（图库不可达时）

- 卡片输出到 `交付/logseq-import/pages/` 完整目录
- 交付说明中给用户导入指引：将 `pages/` 下文件并入本机 Logseq 图库同名目录，重启 Logseq 自动索引

## 入库后查询建议

- 类型查询：`type/概念` `type/金句` `type/方法` `type/疑问`
- 书目查询：`book:: 《书名》` 或页内 `book::` 属性过滤
- 图谱漫游：点开任一卡片在 Graph 视图查看双链网络，跨书概念自动汇聚
