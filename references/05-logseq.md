## pages/ 结构

```
pages/
├── 《书名》.md          书页（元数据 + 一页纸结论 + 章节地图 + 卡片索引）
├── 概念-《书名》-X.md    概念页（费曼解释 + 双链 + 原文锚点）
└── 金句-《书名》-N.md    卡片页（quote/method/question）
```

## Logseq 语法要点

- 属性：`key:: value`（双冒号 + 空格，页面首块）
- 双链：`[[页面名]]`；标签：`#标签`
- 块引用：`((block-id))`（卡片间精确引用时用）
- 金句引用块：`> 原文`（quote 卡正文首行）
- 页面标题用 `# 页面名`；内容用大纲 bullet `-`（Logseq 原生形态）
- 页面首块是属性区，随后是正文

## 入库后查询建议

- 类型查询：`type/概念` `type/金句` `type/方法` `type/疑问`
- 书目查询：`book:: 《书名》` 或页内 `book::` 属性过滤
- 图谱漫游：点开任一卡片在 Graph 视图查看双链网络，跨书概念自动汇聚
