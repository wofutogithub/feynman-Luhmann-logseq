# 卡片盒笔记规范（Zettelkasten）

依据：卢曼卡片盒 + slipbot 前缀/属性规范 + reading-pipeline 引用溯源约束。

## 卡片类型

| 类型 | 触发 | 内容 |
|---|---|---|
| quote 金句卡 | 原文值得引用 | 原文 + 一句话理解 + 出处 |
| concept 概念卡 | 核心概念/术语 | 费曼解释 + 原文锚点 + 相关概念双链 |
| method 方法卡 | 可复用方法/流程 | 步骤 + 适用条件 + 示例来源 |
| question 疑问卡 | 未解问题/反直觉点 | 问题 + 我的思考 + 相关卡片 |

## 原子化原则

- 一卡一想法；一张卡片只回答一个问题
- 用自己的话转述；引用原文必须标注
- 2~4 个对象标签（具体概念/人物/工具，非宽泛分类；如 `#思维模型 #塔勒布`，避免 `#效率`）
- 必须带来源：书 + 章节/页码

## 字段（Logseq 原生 property 语法）

```
card-type:: quote|concept|method|question
book:: [[《书名》]]
source:: 第X章 p.Y
tags:: #tag1 #tag2
```

正文中指向相关概念的链接写明关系类型：related / extends / contradicts / supports（关系说明写入 content，links 字段只放页面名，保证双链不污染）。

## 页面格式（Logseq 闪卡规范，2026-10 定稿）

每张卡片页结构固定为：

```markdown
# 页面名

- card-type:: quote|concept|method|question
- book:: [[《书名》]]
- source:: 第X章 p.Y
- tags:: #tag1 #tag2

### 卡片标题 #card
- 答案行 1
- 答案行 2（多行内容直接换行，每行是一个块，可被 Logseq 块引用）
- 关联：
  - [[概念-《书名》-相关概念]]
```

硬性规则：
1. **标题用 h3 级**：`### 标题`（`###` 后必须加空格再写标题）
2. **闪卡标识**：标题后加空格再写 `#card`，即 `### 标题 #card`，作为 Logseq 闪卡（Card）标记
3. **答案统一缩进下一级**：标题下的答案内容全部用 `- ` bullet 起始（Logseq 树形浏览结构）；多行内容直接换行，每行独立成块，方便日后按块引用
4. **关联二级缩进**：`- 关联：` 下的双链再缩进两级 `  - [[页面名]]`，作为子块
5. 属性区（card-type/book/source/tags）位于页面首块，与正文间空一行

## 命名规范

- 金句/方法/疑问：`类型-《书名》-序号.md`（如 `金句-《预测之书》-01.md`）
- 概念：`概念-《书名》-概念名.md`；跨书概念后续可迁移为独立概念页
- 统一放 Logseq `pages/` 下，与既有中文命名风格一致

## 生成方式

从精读笔记提取结构化卡片数据（JSON），用 `scripts/make_card.py` 批量生成，避免手写格式漂移。

## 生成后校验（必做）

- 断链校验：扫描全部卡片的 `[[...]]` 引用，确认目标文件（页面名）都存在；断链清零后才算完成
- 文件名即 Logseq 页面名：双链引用必须与文件名完全一致（含标点与空格），如 `[[概念-《书名》-X]]`
- 每张卡必含 `type::` 属性；抽查 1~2 张确认属性区与正文格式正确
