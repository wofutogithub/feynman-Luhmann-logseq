# 费曼精读协议

方法依据：费曼四步 + doubao-learn-to-remember（《如何记住你读过的一切》）方法论；可注入 smart-learn 费曼五步提示词增强（概念地图→费曼解释→自测→关联→总结）。

## ① 预览定位（80/20）

- 通读目录、摘要、结论，输出"大局概述"（2~3 句）
- 标出高产出章节：核心论点 / 关键机制 / 反直觉结论 / 可复用清单
- 输出 3~5 个阅读意图问题（把章节标题改写成问题）

## ② 三层渐进笔记

- 层1：每节用自己的话记要点（≤原文 20%，逐条一句）
- 层2：从层1挑最关键的 15%（高亮中的高亮）
- 层3：一页纸执行摘要（核心思想 / 结构 / 可带走的一句话结论）

## ③ 费曼讲解

- 每个核心概念写一段"讲给 12 岁孩子听"的大白话
- 讲不通处标记「待回读」，回原文补齐后才继续
- 每条讲解记录对应章节/页码（强制溯源）

## ④ 自测与联结

- 白纸法自测题：合上材料凭记忆写出要点（留空给用户作答）
- 每概念 ≥1 条跨领域联结："X 是 Y 原理的具体案例"
- 可选：Q&A 闪卡（术语定义 / 机制步骤 / 关键数字 / 人物观点 / 清单）

## 产出

- `02-精读/精读笔记.md`，按①②③④分节组织
- 忠于原文；材料未提供处标注「待核」；不编造
