# 检索方案

## 档位 A：直接读图库（默认，零成本）

- 用户提问 → 在 Logseq 图库 `pages/*.md` 中 grep 关键词 → Read 命中文件 → 综合回答并附来源页
- 适合：概念查找、金句定位、跨书观点比对

## 档位 B：本地 RAG（可选升级）

- 借鉴 kb-rag 思路：中文友好分块（512 字符/64 重叠）+ Ollama `bge-m3` 向量化 + ChromaDB 本地持久化
- 流程：ingest（图库 pages → 向量库）→ query（检索 top-k 片段 → agent 综合回答）
- 前提：本机 Ollama 已装 bge-m3；数据全程不离开本机
- 启用条件：图库卡片 > 500 张，或用户明确要求语义检索
